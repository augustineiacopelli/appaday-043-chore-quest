# 043 · Chore Quest

**AppADay** — one app, every day.

Gamified chore manager for kids. Parents assign quests with XP rewards; kids complete them to level up and compete on a live sibling scoreboard.

## Features

- **Kids view** — tap a quest circle to complete it, triggering a coin-burst animation and XP award
- **XP & leveling** — each kid has a personal XP bar; hitting 100 XP triggers a level-up banner
- **Sibling scoreboard** — ranked leaderboard with gold/silver/bronze medals and color-coded XP bars
- **Quest frequency** — Daily (auto-resets every morning), Weekly (resets on a chosen day), or One-Time
- **Parent mode** — PIN-protected (default: 1234); add/remove kids, assign quests, trigger new day reset
- **First-run onboarding** — guided setup flow; no PIN required until kids are configured
- **Per-kid colors** — each adventurer gets their own color carried through tabs, XP bar, and level badge

## Stack

Single-file vanilla HTML/CSS/JS. No frameworks, no build step. `localStorage` for persistence. Deployable directly to GitHub Pages.
